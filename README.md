🍔 Foodie Delight

A modern, responsive food website built with HTML, CSS, and vanilla JavaScript.

![Foodie Delight Preview](https://via.placeholder.com/800x400?text=Foodie+Delight+Preview)

## ✨ Features

- **Interactive Recipe Section** – View ingredients and step-by-step instructions
- **Food Ordering System** – Add items to cart, view total, and checkout
- **Clean About Us Page** – Team profiles and brand mission
- **Working Contact Form** – With email and phone validation
- **Fully Responsive Design** – Works perfectly on mobile and desktop
- **Smooth Animations & Hover Effects**

## 🛠️ Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Responsive Design
